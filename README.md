# travalor

## 功能

1. 用户可以将当前数据库中去过的景点标记为已打卡.

2. 数据库中的景点可以加入到行程中.

3. 用户可自行增加数据库中没有的景点,根据用户的搜索进行网上搜刮,将该景点加入到景点数据库中,并区分该景点为用户自己所加.

3. 行程规划可选择固定起点终点.

4. 增加活动分类

5. 将景点数据和用户数据存入到本地数据库中,方便数据管理和运营管理.

6. 增加行程前详细准备栏目, 点击某一个行程,跳转到新页面,其中包括行程人员,购路程票check,景点门票check,酒店check,装备准备,装备分类,物品清单,待买清单,其他代办.一些基础的装备物品提供用户选择.
